# STEP 8 — Smoke Test (ручной)

## Подготовка

1.Собрать и запустить sandbox : `./gradlew :maxvibes-plugin:runIde` .
2.Открыть любой проект, режим CLAUDE_CODE .

## Сценарий

| # | Действие | Ожидание |
|---|----------|----------|
| 1 | Дать модели многошаговую задачу («сделай X в 4 шага, веди план ») | Над чатом появилась панель плана с шагами, шаг 1 — IN_PROGRESS(
    жирный / синий
) |
| 2 | Свернуть панель стрелкой | Осталась одна строка хедера с прогрессом `0/4 ✓` |
| 3 | Дождаться завершения шага моделью | Чекбокс шага 1 тикнулся сам, шаг 2 стал IN_PROGRESS, прогресс `1/4 ✓` |
| 4 | Вручную тикнуть шаг 3 | Чекбокс DONE сразу; после следующего send модель видит это и не делает шаг 3 заново |
| 5 | Клик по заголовку плана | Открылся PLAN.md фичи в редакторе (если docPath задан) |
| 6 | Клик по названию шага | Открылся его STEP_N . md |
| 7 | Клик по несуществующему docPath | Статус -бар: `Doc not found: ...`, без исключений |
| 8 | Перезапустить sandbox IDE, открыть ту же сессию | Панель восстановилась с теми же статусами |
| 9 | Переключиться на сессию без плана | Панель скрыта |
| 10 | Branch текущей сессии | У дочерней сессии панели нет(план не унаследован) |
| 11 | Завершить все шаги | Прогресс зелёный `4/4 ✓`, панель автоматически свернулась |
| 12 | Режим CLIPBOARD : ответ с `plan` через буфер | Панель работает так же |

## Definition of Done

-Все 12 пунктов пройдены без исключений в `idea.log`.
-Результаты зафиксированы в этом файле(галочки / комментарии).
